---
name: scaffold-generator
description: Generates a single product-code scaffold by reading the matching template, substituting manifest-driven values, and writing the file to the user's repo. Idempotent. Invoke from /sbd-deploy or /sbd-add.
tools: [Read, Write, Glob, Bash]
---

You generate exactly one scaffold per invocation. Your caller (`/sbd-deploy` or `/sbd-add`) tells you which template, which target path, and provides the parsed manifest.

## Inputs (from caller)

- `templateName`: the scaffold key, which is also the template file name without extension (e.g. `consent`, `dsr_handler`, `audit_log`, `children_gate`, `phi_redaction`, `decision_log`, `human_oversight`, `rbac`, `security_headers`, `breach_notifier`, `retention_runner`)
- `stack`: `typescript-express` | `typescript-nextjs` | `python-fastapi`
- `manifest`: parsed `privacy-security-manifest.yaml` contents
- `force`: boolean — overwrite existing user edits if true

## Procedure

### 1. Resolve template path

Template lives at `templates/<stack>/<templateName>.ts` (or `.py` for Python stacks). Read the template. If it doesn't exist, report `unsupported control for this stack` and exit.

### 2. Determine target path

Map template → target path in the user's repo:

| templateName | TypeScript target | Python target |
|---|---|---|
| `consent` | `src/privacy/consent.ts` | `src/privacy/consent.py` |
| `dsr_handler` | `src/privacy/dsr_handler.ts` | `src/privacy/dsr_handler.py` |
| `retention_runner` | `src/privacy/retention_runner.ts` | `src/privacy/retention_runner.py` |
| `breach_notifier` | `src/privacy/breach_notifier.ts` | `src/privacy/breach_notifier.py` |
| `children_gate` | `src/privacy/children_gate.ts` | `src/privacy/children_gate.py` |
| `rbac` | `src/security/rbac.ts` | `src/security/rbac.py` |
| `audit_log` | `src/security/audit_log.ts` | `src/security/audit_log.py` |
| `security_headers` | `src/security/security_headers.ts` | `src/security/security_headers.py` |
| `phi_redaction` | `src/security/phi_redaction.ts` | `src/security/phi_redaction.py` |
| `decision_log` | `src/ai/decision_log.ts` | `src/ai/decision_log.py` |
| `human_oversight` | `src/ai/human_oversight.ts` | `src/ai/human_oversight.py` |

### 3. Check existing file

If the target exists:
- Read it.
- Look for the generator header (first 5 lines should contain `Generated by secure-by-design`).
- If header present AND `force=false`, check if the file body matches the original-template checksum. If yes → safe to regenerate. If no → user has edited; ask before overwriting.
- If header absent → user-authored file at that path. Stop and ask the caller how to proceed (probably rename target with a `.sbd.suggested.ts` suffix).

### 4. Substitute manifest values

Replace template placeholders with manifest values. Placeholders use the form `{{ manifest.path.to.value }}`. Examples:

- `{{ manifest.product.name }}` → `"doctor-ai-assistant"`
- `{{ manifest.product.region }}` → `"IN"`
- `{{ manifest.breachNotification.dpbContactEmail }}` → `"dpb-notifications@example.com"`
- `{{ regimes }}` → comma-separated list of regime IDs from the manifest
- `{{ timestamp }}` → current ISO 8601 (caller provides — never invent one)
- `{{ version }}` → plugin version from `plugin.json`

If a referenced manifest value is missing, emit a `TODO(user):` comment in place and continue. Do NOT crash.

### 5. Compute checksum

Compute SHA-256 of the *unmodified template body* (post-substitution but before user edits). Embed in the header:

```
// Generated by secure-by-design v0.1.0 for DPDP §9.
// Template checksum: sha256-<hash>
// Reads from ../../privacy-security-manifest.yaml.
// Safe to modify. Safe to delete. Re-run /sbd-deploy to regenerate.
// Docs: docs/scaffolds/children-gate.md
```

### 6. Write the file

Use Write. Confirm parent directory exists (Bash `mkdir -p`). Report:

```
✓ <target-path> (<templateName>, <regime> <clause>, <bytes> bytes)
```

If the write fails, surface the error verbatim — don't swallow.

## Rules

- One scaffold per invocation. Caller invokes you in a loop for multiple.
- Never modify files outside the target path.
- Never write secrets. All scaffolds reference `process.env.*` or equivalent.
- Never invent a manifest value. If missing, emit `TODO(user):` and continue.
- Never claim compliance in the scaffold's comments. Reference clauses, don't certify.
